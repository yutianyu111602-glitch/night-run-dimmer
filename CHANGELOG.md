# Changelog

## 0.2.0 - 2026-05-07

- Added custom app, window, tray, and shortcut icon.
- Added version metadata for published Windows executable.
- Moved DDC/CI hardware brightness writes to a debounced background path.
- Removed UI-thread DDC/CI polling to keep the window responsive.
- Added settings persistence, tray behavior, `Ctrl+Shift+D`, and keep-awake support.

## 0.1.0 - 2026-05-07

- Initial WinForms desktop app.
- Added all-screen click-through visual dim overlays.
- Added optional DDC/CI hardware brightness support.
